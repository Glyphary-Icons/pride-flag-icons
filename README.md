# Glyphary Pride Flags

An open, growing collection of full-color LGBTQIA+ pride flag SVGs. Each flag is a standalone, responsive SVG asset in this repository—no website, build step, package install, or external asset repository is required to use the files.

## Browse the collection

The `flags/` directory is organized by topic:

- [`community/`](flags/community/) — community flags
- [`gender/`](flags/gender/) — gender identity flags
- [`inclusive/`](flags/inclusive/) — inclusive and progress flag variations
- [`intersex/`](flags/intersex/) — intersex flag
- [`orientation/`](flags/orientation/) — romantic and sexual orientation flags
- [`relationships/`](flags/relationships/) — relationship and polyamory flags

Every SVG has a descriptive filename and can be opened directly in a browser, design tool, or vector editor. `flags.json` is a lightweight catalog with each asset's display name, category, search tags, and relative file path; the SVGs are the source assets.

## Use

Copy or link to any `.svg` file directly. The assets use a `300 × 200` viewBox and retain their colors when scaled. They are not designed to inherit `currentColor` or be recolored by the Glyphary website.

## Color and design notes

Colors and designs reflect community conventions, which may vary. Some flags have multiple commonly used variations and no single universally adopted specification. This collection documents selected renditions rather than claiming that any rendition is universally official or that the collection is exhaustive. Color references inform choices only; all SVG artwork in this collection is authored specifically for this repository.
